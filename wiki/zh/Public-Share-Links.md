# 公开分享链接

把旅行的只读视图分享给没有 Tourism-Team 账户的人。查看者无需登录即可在浏览器中打开。

![公开分享链接](assets/Share.png)

## 创建分享链接

打开你的旅行，点击顶部导航栏中的 **分享** 按钮（用户图标）。这会打开「成员与分享」弹窗。分享链接区域出现在弹窗右侧，仅对拥有 `share_manage` 权限的用户可见（默认是旅行所有者和管理员）。

点击 **创建链接** 生成令牌。

分享 URL 的形式为：

```
<your-instance>/shared/<token>
```

复制这个 URL，发给你想分享该旅行的任何人。查看它不需要 Tourism-Team 账户。

### 链接的有效期

分享链接自最后一次保存起算，有效期为 **90 天**。创建链接时会写入 90 天的过期时间，而翻转任意一个未锁定的权限开关都会重新保存该链接并写入新的过期时间，因此你主动管理的链接永远不会在你不知情时失效。

90 天到期后，访问者会看到 **链接已过期或无效**。「成员与分享」弹窗中的分享区域不会显示这一点 —— 它会继续显示 URL 和 **删除链接** 按钮，因为所有者侧的查询会忽略过期时间。没有任何过期徽章来提醒你。

要恢复已失效的链接，翻转任意一个未锁定的开关 —— **预订**、**行李**、**费用** 或 **聊天** —— 如果你并不想改变任何东西，再翻转回来。**地图与计划** 是锁定的，因此点击它不会发出任何请求，也无法恢复链接。翻转一个未锁定的开关会为 **同一个** 令牌重新保存 90 天，旧 URL 又会开始工作。如果你想要一个真正不同的 URL（例如旧 URL 泄露了），请使用 **删除链接**，然后再 **创建链接**。

在 Tourism-Team 加入过期机制之前创建的链接不带任何过期时间，会一直有效。你第一次更改它们的某个开关时，那次保存就会把它们像其他所有链接一样纳入 90 天的计时。

## 权限开关

创建或更新分享链接时，你可以选择接收者能看到什么。可用的开关如下：

| 开关 | 默认值 | 显示内容 |
|--------|---------|---------------|
| **地图与计划**（`share_map`） | 始终开启 | 带有交互式地图和逐日行程的「计划」标签页。该开关被锁定为开启，无法从界面中禁用；若某个链接的该标志在界面之外被关闭，它就没有「计划」标签页，服务器也会完全扣下其天数、地点和备注。 |
| **预订**（`share_bookings`） | **开启** | 包含预订和交通的「预订」标签页。还控制交通条目是否内联显示在日程计划中。 |
| **行李**（`share_packing`） | 关闭 | 按分类分组的行李清单标签页 |
| **费用**（`share_budget`） | 关闭 | 带总计摘要和按分类分组明细行的「费用」标签页 |
| **聊天**（`share_collab`） | 关闭 | 按时间顺序显示消息的只读「聊天」标签页 |

被禁用的开关会从公开查看器中完全隐藏对应的标签页。权限更改立即生效 —— 你无需重新创建链接。

### 访客看到哪种货币

公开查看者没有账户，因此不存在「他的」显示货币可用。「费用」标签页以 **分享者的显示货币渲染，并回退到旅行自身的货币** —— 换句话说，访客看到的金额与分享该旅行的人看到的一样。如果分享者把自己的显示货币留作 **旅行货币**（默认值），访客就会以旅行自身的货币来查看该旅行。见 [货币](Currencies)。

## 公开查看器显示什么

共享旅行页面渲染出一个带品牌标识的只读界面，顶部是深色的主视觉页头，显示旅行标题、描述和日期范围。顶部的标签栏提供对你已启用各区域的访问。查看者可以用右上角的语言选择器切换显示语言。

只要 **地图与计划** 开启，「计划」标签页就会出现 —— 通过分享界面创建的每个链接都是如此，因为该开关在那里被锁定为开启。若某个链接的 `share_map` 标志在界面之外被关闭（通过 REST API 或 `create_share_link` MCP 工具，两者都把它当作普通布尔值接收），它就完全没有「计划」标签页：服务器会完全扣下天数、地点、分配和备注，查看器会打开在所有者确实分享过的第一个区域上。**日期选择器** 就位于地图正上方 —— 一个 **全部** 胶囊按钮加上每天一个胶囊按钮（**第 1 天**、**第 2 天**……）—— 它与下方的日期卡片驱动同一个选择，因此地图和展开的当天永远不会不一致。选中某一天后，其站点会按游览顺序在地图上编号（当天重复到访的地点会在同一个标记上显示两个位置，例如 `1 · 3`），并由一条虚线连接线相连。该连接线是表示先后顺序的直线，而不是驾车路线：Tourism-Team 不会代表匿名访问者把共享行程发送给第三方路线服务。选择 **全部** 时，地图会把每个已定位的地点显示为不带编号的图钉，且没有连接线。地图下方是可折叠的逐日行程（启用「预订」时内联显示地点、备注和交通）以及每天的住宿徽章。

「聊天」标签页（通过 `share_collab` 启用时）显示按日期分组、带发送者头像的聊天消息。查看者无法发送消息。

## 撤销分享链接

打开导航栏中的「分享」按钮，然后在分享链接区域点击 **删除链接**。现有 URL 会立即对所有持有它的人失效。

## 旅程公开分享

旅行日志（旅程扩展）有一套独立的分享机制，拥有自己的令牌命名空间和权限标志（时间线、图库、地图）。详情见 [旅程](Journey-Journal)。
