# 行程规划器概览

行程规划器是构建行程的主要工作区。在仪表盘上点击一张旅行卡片即可打开它。

![行程规划器](assets/TripPlannerWithPlane.png)

## 布局

在桌面端，规划器采用 **三栏可调整大小的布局**：

```
┌─────────────────┬──────────────────────────┬──────────────────┐
│  Day Plan       │                          │  Places          │
│  Sidebar        │       Interactive        │  Sidebar         │
│  (left)         │          Map             │  (right)         │
│                 │        (center)          │                  │
└─────────────────┴──────────────────────────┴──────────────────┘
```

- **左侧栏** —— 日程计划：你的天数列表、已分配的地点、备注和交通条目。可通过面板切换按钮折叠。
- **中间** —— 交互式地图，显示所有地点标记和当天路线。
- **右侧栏** —— 地点列表：搜索、分类筛选和批量操作。可折叠。

每个侧边栏的内侧边缘都有一个用于调整大小的拖拽手柄。

![三栏布局的规划器：左侧是包含天数、地点、备注和航班条目的日程计划侧边栏，中间是地图，右侧是带搜索和分类筛选的地点侧边栏](assets/TripPlanner.png)

当你打开某一天时，**日程详情面板** 会浮动在地图区域上方，显示天气预报、当天的预订和住宿区块。它可以折叠成细窄的标题栏而不必关闭。

## 标签页

标签栏位于主导航栏的正下方。

| 标签页 | 说明 |
|---|---|
| **计划** | 上文所述的三栏地图视图。始终可见。 |
| **交通** | 航班、火车、汽车、邮轮和巴士。 |
| **预订** | 酒店、餐厅、活动、旅游团和其他预订。 |
| **列表** | 行李清单和待办事项列表。 |
| **费用** | 支出记录、分摊和结算。 |
| **文件** | 用于收据、票据和其他文件的文档管理器。 |
| **协作** | 实时聊天、共享笔记和投票。 |

> **管理员：** **列表**、**费用**、**文件** 和 **协作** 标签页仅在对应的扩展启用时才出现。见 [管理：扩展](Admin-Addons)。

当前激活的标签页按旅行保存在 `sessionStorage` 中，因此在旅行之间切换时会保留你上次的位置。

## 移动端布局

在窄于 768 px 的屏幕上，Tourism-Team 不会强行压缩三栏布局 —— 而是打开专门的移动端旅行屏幕：顶部栏下方是一条日期胶囊轨道，日程计划与全屏地图之间可切换，其他标签页则放在底部停靠栏中。平板和桌面端（768 px 及以上）使用上文所述的三栏布局。

## 撤销

规划器会把你最近的操作 —— 添加地点、把地点分配到某天、重新排序和移除分配 —— 记录在一个简短的撤销环中。**撤销** 按钮位于日程计划侧边栏工具栏中（侧边栏顶部）；在有可撤销的操作之前它一直处于置灰状态。悬停时它会以提示形式显示上一次操作的名称，点击即撤销该操作。

## 启动画面

首次打开旅行时，在拉取规划器数据和地点照片期间会出现一个简短的加载画面。该画面显示旅行标题和一个加载动画。数据就绪、并经过一段短暂的照片宽限时间后，规划器工作区便会显示。
