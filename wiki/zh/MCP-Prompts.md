# MCP 提示词

Tourism-Team 内置了 MCP 提示词 —— 预置的上下文加载器，告诉你的 AI 客户端如何以结构化方式汇总或呈现你的行程数据。提示词是 MCP 的标准功能：兼容的客户端可以按名称调用它们，为常见任务获得一个现成的起点。

## 内置提示词

| 提示词 | 所需扩展 | 说明 |
|---|---|---|
| `trip-summary` | — | 加载一次行程的格式化摘要：日期、成员列表、天数、每天的地点数量、行李进度、预算总额、预订数量和协作笔记数量。在要求 AI 规划或修改行程之前使用它。 |
| `packing-list` | 行李清单 | 返回一次行程的完整行李清单，按分类分组，每个物品标记为已勾选或未勾选。 |
| `budget-overview` | 费用 | 返回一次行程的预算摘要 —— 总支出、按分类的明细（降序排列），以及按人估算的费用。 |
| `token_auth_notice` | — | 针对使用静态 `trek_` 令牌认证的会话的弃用通知。仅在静态令牌会话中可用。它说明该令牌将在未来版本中停止工作，以及如何迁移到 OAuth 2.1。 |

`packing-list` 和 `budget-overview` 只有在你的 Tourism-Team 实例上启用了对应的扩展时才会注册。

`token_auth_notice` 只有在当前会话使用旧式静态 API 令牌认证时才会注册 —— 它不会出现在 OAuth 会话中。

## 如何使用提示词

在兼容的 MCP 客户端（例如 Claude.ai 或 Claude Desktop）中，提示词通常以斜杠命令或提示词面板的形式出现。你选择提示词，提供任何必需的参数（例如 `tripId`），客户端会在你的下一条消息之前把格式化后的上下文发送给 AI。

例如，用某个行程 ID 调用 `trip-summary`，会让 AI 获得该行程的一份紧凑快照 —— 天数、成员、预算、行李 —— 而无需逐个调用多个工具。
