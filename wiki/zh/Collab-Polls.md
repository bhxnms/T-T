# 协作投票

创建群组投票来共同做决定 —— 去哪里吃、住哪家酒店、空闲的一天做什么。

![一个包含三个选项和当前票数的旅行投票](assets/CollabPolls.png)

## 在哪里找到它

打开行程规划器 → **协作**标签页 → **投票**区域。必须启用协作扩展，且投票子功能必须开启。见[实时协作](Real-Time-Collaboration)。

## 创建投票

拥有 `collab_edit` 权限的用户可以点击投票标题栏中的 **+ 新建投票**。会打开一个包含以下字段的对话框：

| 字段 | 必填 | 说明 |
|---|---|---|
| 问题 | 是 | 投票的提问 |
| 选项 | 是 | 至少需要 2 个选项；用 **+ 添加选项** 添加更多 |
| 多选 | 否 | 开启后允许投票者选择多个选项 |
| 截止时间 | 否 | 仅移动端；超过该日期时间后投票自动关闭 |

点击**创建投票**保存并把投票广播给所有已连接的成员。

## 投票

点击某个选项按钮即可投票。实心圆点和蓝色高亮表示你的选择。对于**多选**投票，你可以点击更多选项来选择多个；点击已选中的选项会撤销你对该选项的投票。对于**单选**投票，点击不同选项会把你的投票移到新的选择上。

投票者头像和数字百分比只有**在你投票之后**，或投票已关闭或已过期时才可见。每个选项后面的填充条始终会绘制，在你投票之前是一种淡淡的中性色调；投票标题栏中的总票数对所有人可见 —— 因此在你投票之前就能看出大致分布。

## 结果

每个选项显示：

- 一条按所获票数比例展开的**百分比填充条**
- 堆叠在选项旁边的至多 **3 个投票者头像标签**
- 右侧边距中的**百分比**

投票关闭或过期时，得票最多的选项会被高亮。

## 截止时间

投票可以带有可选的截止时间。在**移动端**，新建投票面板有一个**截止时间**字段 —— 一个带清除按钮的日期时间选择器。桌面端的创建对话框尚未提供该字段，因此在桌面端只能通过 API 或 MCP 设置截止时间。存在截止时间时，投票卡片上会出现一个实时倒计时徽标，每 **30 秒**更新一次。该徽标以天/小时/分钟的格式显示剩余时间。

截止时间过后，投票会被自动视为已关闭：投票被禁用，结果向所有人显示。

## 手动关闭投票

拥有 `collab_edit` 权限的用户可以点击未关闭投票上的锁图标立即关闭它。一旦关闭，投票将被永久禁用。

## 删除投票

拥有 `collab_edit` 权限的用户可以使用垃圾桶图标删除投票。删除是永久的，会对所有成员移除该投票。

## 进行中和已关闭区域

未关闭的投票出现在列表顶部。已关闭或已过期的投票会移到进行中投票下方的**已关闭**区域。
